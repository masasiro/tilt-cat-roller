# Tilt Cat Roller

スマホを傾けてネコを転がし、止まらずにゴールを目指す1ページゲームです。iPhone Safariを優先しつつ、Android Chromeでも動く想定です。

## 遊び方
1. 画面の「センサーを有効にする」ボタンを押します。
2. スマホを傾けてネコを転がし、ゴールを目指します。
3. DIZZYゲージが100になると目が回り、操作が鈍くなります。止まって回復しましょう。
4. 緑のCOOLゾーンに乗ると走りながら回復できます。

## 操作方法
- iOSは `DeviceOrientationEvent.requestPermission()` の許可が必要です。許可後に傾き操作が有効になります。
- 許可を拒否した場合やセンサーが使えない場合は、画面下の仮想ボタン（上下左右）で操作できます。

## 仕様メモ
- Canvas論理解像度: 360x640
- HUD高さ: 90px
- 外部ライブラリ/画像/音声は使用していません。

## ローカルでの起動方法
ビルド不要です。次のコマンドで起動できます。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000` を開いてください。
