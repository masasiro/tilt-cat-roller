# Tilt Cat Roller

スマホを傾けて「かわいいネコ」を転がし、ゴールを目指す1ページWebゲーム。

## 遊び方

1. **スタート**: 画面の「センサーを有効化してスタート」ボタンを押します。
   - **iOSの方**: ポップアップで「動作と方向へのアクセス」を求められたら**許可**してください。
   - **Android/PCの方**: そのまま開始します。
2. **操作**:
   - **スマホ**: 本体を傾けてネコを転がします。
   - **PC/センサー不可**: 画面下の仮想ボタンまたはキーボード（矢印キー）で操作します。
3. **ルール**:
   - ゴール（右上の黄色い円）にたどり着けばクリア！
   - **DIZZY（めまい）**: 走り続けると目が回ります。ゲージがMAXになると操作しづらくなります。
   - **回復**: 止まるとゲージが回復します。緑色の「COOLゾーン」なら走りながらでも回復できます。
   - **路面**: 茶色の「ROUGHゾーン」は疲れやすいので注意。

## 技術仕様

- ビルド不要、外部ライブラリ不使用。
- HTML5 Canvas + DeviceOrientation API。
- モバイルファースト（縦画面固定）。
